====================
Text indentation
====================

Import the function:
>>> text_indentation = __import__('5-text_indentation').text_indentation

Check that plain text has no final newline:
>>> import io
>>> from contextlib import redirect_stdout
>>> output = io.StringIO()
>>> with redirect_stdout(output):
...     text_indentation("Holberton School")
>>> output.getvalue()
'Holberton School'

Print text with two newlines after each selected punctuation mark:
>>> text_indentation("Hello. World? Again: done")
Hello.
<BLANKLINE>
World?
<BLANKLINE>
Again:
<BLANKLINE>
done

Trim whitespace around each printed line:
>>> text_indentation("  Hello.   World?  ")
Hello.
<BLANKLINE>
World?
<BLANKLINE>

>>> text_indentation("first line\n   second line")
first line
second line

Print nothing for empty text:
>>> text_indentation("")

Reject values that are not strings:
>>> text_indentation(42)
Traceback (most recent call last):
TypeError: text must be a string
