====================
Integer addition
====================

Import the function:
>>> add_integer = __import__('0-add_integer').add_integer

Add integers and use the default value:
>>> add_integer(1, 2)
3
>>> add_integer(100, -2)
98
>>> add_integer(2)
100

Convert floating-point values to integers before adding:
>>> add_integer(100.3, -2)
98
>>> add_integer(-2.9, 1.8)
-1
